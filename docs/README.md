## Documentation Standards

All documentation in this project follows:
- **Naming**: Lowercase kebab-case for files and folders
- **Format**: Markdown (.md) for all documentation
- **Structure**: Organized by purpose and audience
- **Model Tracking**: All AI-generated content documented in [models.md](./ai/models.md)

## Contributing to Documentation

When adding new documentation:
1. Place it in the appropriate folder based on its purpose
2. Use lowercase kebab-case for filenames
3. Add an entry to the relevant README.md index
4. Update cross-references in related documents
5. Follow the PRD template for requirements documents
