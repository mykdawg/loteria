## Key Principles

### Mandatory Workflows
- ✅ **PRD First**: Create requirements document before coding
- ✅ **Test Coverage**: Maintain 80%+ code coverage
- ✅ **Code Review**: Complete checklist before committing
- ✅ **Model Documentation**: Track all AI-generated code

### Code Quality Standards
- Follow import order conventions
- Use proper naming conventions (camelCase, PascalCase, UPPER_CASE)
- Write clear, descriptive commit messages
- Include accessibility attributes (ARIA, keyboard navigation)
- Support bilingual content (Spanish/English)

### Cultural Considerations
- Maintain authentic Mexican cultural elements
- Use traditional Spanish card names
- Respect cultural significance of Lotería tradition

---

## Documentation Standards

2. Include generation date and context
3. Track human reviews and modifications
